Route Rush Problem Statement

Design and develop an application that optimizes the delivery and installation of modular cabins across multiple project locations in India.

Each project location requires one cabin, and cabins are manufactured at three different factories. The goal is to plan the logistics in such a way that deliveries and installations happen efficiently, with minimal delays and inventory buildup.

Scenario

You are given:

  • Up to 600 project locations (user input via map or manual entry)
  • 3 factory locations
  • Each location requires 1 cabin

Delivery Constraints

  • Each truck carries exactly 3 cabins per trip
  • Each trip must deliver to 3 different locations
  • Truck route format: Factory → Location 1 → Location 2 → Location 3
  • Truck speed is 40 km/h
  • Trucks are assumed to be unlimited and can make multiple trips if required

Factory Constraints

  • Each factory produces X cabins per week (user-defined input)
  • Each factory can store a maximum of 6 cabins at any time

Installation Constraints

  • Each cabin takes 4 hours to install
  • Installation begins immediately after delivery
  • Multiple installations can occur in parallel across locations

Inventory Definition

Inventory includes:

  • Cabins waiting at the factory
  • Cabins delivered to a site but not yet installed

Requirements

Your application should allow users to:

  • Input: Project locations, Factory locations, Weekly production rate per factory
  • Generate: Grouping of locations into batches of 3, Assignment of each batch to a factory, Optimized delivery routes for each truck, Delivery and installation schedules

Objectives

Your solution must aim to:

  • Minimize the maximum waiting time (Time between delivery and installation of any cabin)
  • Minimize total inventory (Across factories and project sites)
  • Ensure the project is completed as early as possible
  • Efficient clustering logic

Expected Outcome

The final output should include:

  • Optimized truck routes
  • Delivery plan
  • Installation schedule
  • Visualization using maps or timelines

Hugging Face AI Integration (MANDATORY for Innovation points)

Use google/flan-t5-small via Hugging Face Inference API (huggingface_hub.InferenceClient).

  • After plan generation, the model must create a natural-language “AI Insights & Recommendations” section: why batches/routes were chosen, 1-2 alternative clustering ideas, potential bottlenecks.
  • User enters their own free Hugging Face API token (Settings page).
  • Toggle “Enable AI Insights” (default: on).
  • Only Inference API – no local model download.
  • You will give exact integration guidance (pip install, code, security) in the relevant parts while in Agent Mode.

Home Page Requirement: Clean landing page only – logo, big title “Route Rush”, short tagline “Optimize Modular Cabin Delivery & Installation Across India”, three big buttons (Start Inputs → Generate Plan → View Results), and a small “About the Challenge” link that opens a separate modal or page with the full problem statement above. Do NOT display the entire problem statement on the home page.

Development Rules

  • Generate code in exactly 15 sequential parts.
  • Use in-memory session storage + simple dicts (or SQLite if needed later).
  • Implement haversine distance, greedy nearest-factory clustering, brute-force 3-location route ordering, and full time-based simulation.
  • Default test coordinates around Salem, Tamil Nadu, India.
  • Mostly let the user “vibe code”; give assistance only when Hugging Face or complex logic is needed.
  • The user already has a basic Flask boilerplate in VSCode (app.py, templates/, static/css/, static/js/).

Exact 15-Part Breakdown (follow strictly)

  1. Base Flask structure + clean Home landing page (no full problem statement) + basic navbar.
  2. Complete style.css – all global styles exactly matching the design described above.
  3. Inputs page – Factory section (3 factories with name, lat, lng, weekly X rate).
  4. Project locations input – dynamic add form, table list (delete), CSV upload.
  5. Interactive Leaflet map on Inputs page (click to add/edit factories & locations).
  6. Backend data layer (session-based storage).
  7. Clustering logic – assign to nearest factory + group into exact batches of 3.
  8. Route optimization – best order for each batch of 3.
  9. Scheduling & inventory simulation (production, delivery times, 4h install, inventory tracking).
  10. Objective calculations (max wait time, total inventory, completion time).
  11. Hugging Face Integration Part 1 – Settings page for API token + helper function get_ai_insights().
  12. “Generate Plan” endpoint + full results storage (with optional AI call).
  13. Results page – batches, routes, delivery plan + AI Insights panel.
  14. Installation schedule + performance stats + map visualization with colored routes.
  15. Final polish: Chart.js Gantt timeline, download options, full AI Insights page, error handling, footer with contact & evaluation table, responsiveness, testing notes.
